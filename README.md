# BGYHub

### One API. Multiple Leading AI Models.

BGYHub is a unified AI API gateway built for developers using Claude, GPT,
AI coding tools, agents, and applications.

Instead of managing multiple providers, API keys, balances, and usage dashboards,
BGYHub gives you one place to access and manage your AI workloads.

> 🚧 BGYHub is currently in Beta.
> We are looking for our first 10 developers to test the platform with real workloads.

## Why BGYHub?

Developers working with multiple AI models often have to manage:

- Multiple API providers
- Different API keys
- Separate balances and billing
- Different usage dashboards
- Model switching and configuration

BGYHub simplifies this into:

**One Account → One API → Multiple AI Models**

## Supported Workflows

BGYHub is designed for:

- Claude Code
- Codex
- AI Agents
- Developer tools
- Custom applications
- Multi-model AI workflows

Model availability may change during Beta as we continue testing and expanding
provider support.

## Developer Dashboard

Every BGYHub account includes a developer portal where you can monitor:

- Current balance
- API usage
- Successful and failed requests
- Token consumption
- Model usage
- Recent requests
- Billing history

No guessing where your API credits went.

## Quick Start

Your BGYHub API endpoint:

https://api.bgyhub.com/v1

After receiving your Beta API key, you can connect supported tools and
applications to BGYHub using the provided endpoint and credentials.

Detailed setup guides are coming for:

- Claude Code
- Codex
- API integrations

## Built for AI Coding

BGYHub is especially focused on developers using AI coding tools.

Use one account to experiment with different supported models without managing
multiple provider accounts and billing systems.

## China Beta

For developers in China, Beta users can request manual top-ups using:

- Alipay
- WeChat Pay

BGYHub account balances remain denominated in USD.

Payment support during Beta is currently handled manually.
